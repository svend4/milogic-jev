# Таро и символические системы как рекомендательный слой

## Идея

Не гадание.  
Таро (и аналогичные системы) читаются как **каталог двойственных отношений** (монад).  
Jev-стиль вопросов оценивает эти монады против реального состояния (бизнес, проект, рынок).  
Результат — структурированная рекомендация для Lebensberater / предпринимателя.

## Что реализовано

- `MAJOR_ARCANA_BUSINESS` — 22 старших аркана как бизнес-монады
- `build_tarot_business_catalog()` — иерархический каталог
- `build_domain_catalog("trade"|"service")` — каталоги для торговли и услуг
- `SymbolicAdvisor` — интерфейс: состояние → рекомендация + предложения следующего уровня
- `recommend_from_results()` — перевод замыкания в действие

## Варианты

| Вариант | Описание |
|---------|----------|
| Статический расклад | Фиксированный набор арканов как монад |
| Доменный каталог | Только двойственности торговли или услуг |
| Генеративный | При сильном замыкании предлагается следующий уровень |
| Референс-фреймы | Одна ситуация через несколько символических систем |
| Временной | Сравнение «до / после» |

## Научно-популярная рамка

«Символические системы как интерфейс к иерархии двойственных отношений.  
Оценка через калиброванные вопросы вместо свободной интерпретации.»
