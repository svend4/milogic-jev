# Новые классы систем принятия решений на основе Jev + Милогия

Jev = плоский каталог типизированных вопросов (Noul / Choice / Score), параллельно оцениваемых против одного state, с калиброванными вероятностями.

Милогия = иерархия двойственных отношений (монад), которые замыкаются в новые уровни «по образу и подобию», с оболочками, подоболочками и ограниченностью уровней.

## Класс 1. Иерархический каталог вопросов (Hierarchical Question Shells)

Вопросы организованы в оболочки. Ответы нижней оболочки становятся частью состояния для верхней.

Подвиды: жёсткая иерархия, динамическая (по замыканию), вложенные подоболочки.

## Класс 2. Монадные вопросы (Monad Questions)

Новый примитив. Возвращает доминирующий полюс, силу замыкания, флаг порождения следующего уровня и тип отношения.

Подвиды: статическая, открытая, мультимонада, с временной динамикой.

## Класс 3. Генеративные каталоги

Каталог порождает кандидатов следующего уровня по правилу преемственности / замыкания.

## Класс 4. Системы смены системы отсчёта

Один state прогоняется через несколько наборов критериев. Ищется наиболее стабильная система отсчёта.

## Класс 5. Композиция через явное замыкание

Композиция ответов происходит по правилам замыкания, а не только во внешнем коде.

## Класс 6. Многоуровневое состояние

State сам имеет иерархическую структуру. Вопросы могут адресоваться к конкретным уровням.

## Класс 7. Калибровка двойственностей

Специализированная система для оценки устойчивости и замкнутости двойственных отношений.

## Класс 8. Гибриды

Jev + внешняя оркестрация, монада как шаблон, двухконтурные системы.
