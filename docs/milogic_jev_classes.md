# Новые классы систем на основе Jev + Милогия

## Классы

1. **Иерархический каталог вопросов** (Hierarchical Shells) — оболочки, передача результатов вверх, динамическое замыкание.
2. **Монадные вопросы** (Monad Questions) — новый примитив: двойственное отношение с оценкой замыкания и порождения уровня.
3. **Генеративные каталоги** — преемственность по образу и подобию, генерация через замыкание.
4. **Смена системы отсчёта** — параллельный перебор критериев, поиск инварианта.
5. **Композиция через замыкание**.
6. **Многоуровневое состояние**.
7. **Калибровка двойственностей**.
8. **Гибриды**.

Полная версия с примерами и схемами находится в локальных артефактах и может быть добавлена при необходимости.

Рекомендуемый минимум: монада + иерархический каталог с правилом замыкания.
