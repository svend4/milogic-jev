# Поэтапная реализация всех классов Milogic-Jev

## Этап 0. Подготовка

1. Доступ к модели типа Jev (или аналогу), которая принимает `state` + типизированные вопросы и возвращает калиброванные ответы.
2. Оркестратор из `core.py`.

## Этап 1. Монада как шаблон

Даже если модель не знает тип `monad`, собрать её из стандартных вопросов через `MonadQuestionBuilder.as_jev_questions()`.

## Этап 2. Иерархический каталог

Использовать `HierarchicalCatalog`. Добавлять уровни с `condition`. Результаты нижнего уровня автоматически попадают в состояние верхнего.

## Этап 3. Правило замыкания

Если `closure >= 0.78` и `generates_higher_level == true` — предлагать следующий уровень.

## Этап 4. Смена системы отсчёта

Несколько наборов вопросов на один и тот же state. Выбор наиболее стабильного.

## Этап 5. Генеративный каталог

Накопление успешных монад → генерация формулировок следующего уровня по подобию → проверка стабильности.

## Этап 6–8

Многоуровневое состояние, калибровка статистики замыканий, полный цикл работы.

## Следующие шаги

1. Подключить реальный вызов Jev в `evaluate`.
2. Прогнать 5–10 двойственностей из текстов Беляева.
3. Зафиксировать, какие дают устойчивое замыкание.
4. Уточнить пороги.
