# Milogic-Jev

Новые классы систем принятия решений, сочетающие:
- структурированные типизированные вопросы и калибровку (принцип Jev),
- иерархию двойственных отношений, замыкание и «образ и подобие» (принципы милогии Беляева).

## Структура

- `core.py` — основные классы
- `STEP_BY_STEP.md` — поэтапная инструкция
- `docs/milogic_jev_classes.md` — таксономия
- `docs/milogic_jev_implementable.md` — схемы и примеры
